# YOLO Model Weights Directory

Place your custom trained `.pt` or `.onnx` weight files in this directory.

Examples:
- `best_vehicle.pt` (Vehicle Detection & Tracking)
- `best_anpr.pt` (License Plate Recognition)
- `best_pothole.pt` (Pothole & Surface Defect Detection)
- `yolov8n.pt` (Standard YOLOv8 Base Model)
